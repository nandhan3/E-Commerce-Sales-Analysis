# E-Commerce Sales & Profit Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data using
Microsoft Excel and Power BI to identify sales trends, product
performance, category-level insights, and overall business patterns.

## 🎯 Objectives

- Analyze e-commerce sales and profit data
- Identify sales trends over time
- Analyze product and category performance
- Compare regional/state-level performance
- Identify top-performing products
- Build an interactive Power BI dashboard
- Generate actionable business insights

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization
- Data Analysis

## 📂 Dataset

The dataset contains e-commerce transaction-level data used for
sales, profit, product, category, payment-mode, and time-based
analysis.

## 🔄 Data Preparation

The following data preparation steps were performed:

- Removed duplicate records
- Handled missing values
- Standardized data formats
- Validated numerical fields
- Formatted date columns
- Prepared data for visualization and analysis

## 📊 Dashboard Features

The Power BI dashboard includes:

- KPI Cards
- Sales Analysis
- Profit Analysis
- Monthly Sales Trend
- Product Performance
- Category Analysis
- State/Region Analysis
- Payment Mode Analysis
- Interactive Slicers

## 📈 Key Insights

- Identified monthly sales trends
- Analyzed high-performing products
- Compared product categories
- Evaluated regional/state performance
- Examined sales and profit patterns
- Identified areas for business improvement
